# 機器A 通信仕様（デモ用の架空仕様）

このファイルをコピーして対象に合わせて編集してください。機種、バージョン、取得条件は利用者が確認します。

## 適用範囲

- 機種: 合成デモ機器A
- バージョン: demo-1
- TCPサーバーポート: 5000
- バイト順: ビッグエンディアン
- 暗号化なし

## メッセージ構造

TCPバイト列から長さフィールドでメッセージを復元します。1パケット=1メッセージとは限りません。

| オフセット | 長さ | 内容 |
|---|---|---|
| 0 | 2バイト | ヘッダーを含むメッセージ全体長 |
| 2 | 1バイト | コマンドID |
| 3 | 1バイト | 要求番号 |
| 4 | 可変 | データ |

## 要求・応答

- 0x01: 状態取得要求。対応応答は0x81。
- 応答は同じ要求番号を返す。
- このデモでは同一接続内で要求番号を再利用しない。
- 観測上、要求全体の受信完了から応答全体の受信完了まで500ms以内を期待する。
